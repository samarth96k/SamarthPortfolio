## 💡 About the Project

This is a modern, responsive personal portfolio website built using **React** and custom CSS. Its goal is to present my professional profile, contact links, and downloadable resume in a clean, engaging format.

### Features

- Fully **responsive design** for mobile, tablet, and desktop screens.
- Interactive **top bar** with social and contact links (LinkedIn, GitHub, LeetCode, Instagram, Email, WhatsApp).
- **Typing animation** in the hero section for dynamic intro text.
- **Downloadable Resume** button.
- Smooth animations and interactive UI elements.

---

## 🛠 Technologies Used

- **React** – JavaScript UI library for component-based rendering.
- **CSS** – For styling and layout.
- **HTML / JSX** – Markup structure for React components.
- **GitHub Pages** – To deploy the site.
- **EmailJS** - EmailJS for sending mails from contact page to address queries of collaboration, bug fixes or anything else.
